## Prueba Técnica Vue / Nuxt

Este repositorio contiene el desarrollo de las preguntas solicitadas en la prueba técnica relacionada con Vue.js, Nuxt.js y tecnologías complementarias.

## Estructura del repositorio

Cada pregunta ha sido desarrollada por separado y se encuentra organizada en su propia carpeta, con su respectiva funcionalidad y código:

- **Pregunta 1**: Rutas dinámicas en Nuxt 2 para listar publicaciones desde una API externa.
- **Pregunta 2**: Script Node.js que modifica un archivo JSON local agregando la fecha actual.
- **Pregunta 3**: Consumo de campos ACF desde WordPress Headless usando REST API en Nuxt.
- **Pregunta 4**: SCSS para grilla responsive cumpliendo estándar WCAG AA.
- **Pregunta 5**: Flujo de trabajo con Git con ramas, explicando sus pasos.
